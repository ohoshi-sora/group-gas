# 授業グループワーク管理システム（Google Apps Script）

## 背景

毎週グループワークを行う授業では、学生ごとに「どの時間帯（クール）に参加するか」と「どの班に入るか」を決める必要があります。受講者が100人を超えると、申請の受付、本人確認、定員管理、班分け、結果の公開を手作業で回すのは負担が大きく、ミスも起きやすくなります。

このスクリプトは、Google フォームと Google スプレッドシートだけを使って、この一連の作業を自動化します。サーバーや外部サービスは使いません。

## できること

- 学生がフォームでクール（第1〜第4）または BC（ベーシッククラス）を申請し、先着順・定員つきで振り分ける
- 申請時に4桁のパスワードで本人確認する（パスワードは大学メールアドレス宛に自動送信）
- 授業開始前に、全受講者へ初回パスワードを数日に分けて送信する（MailApp の1日あたりの送信上限への対策）
- クールごとにランダムに班を作り、管理者が確認・修正してから学生用シートに公開する
- 当日参加の学生を空いている班に追加する
- 週ごとに「フォーム受付開始 → 締切 → 班分け → 公開 → 初期化」をトリガーで自動実行する

## 必要なもの

| 種類 | 名前（例） | 用途 |
| --- | --- | --- |
| スプレッドシート | 管理用（Form_GAS） | このスクリプトを紐づける。2つのフォームの回答先にもする |
| スプレッドシート | 学生共有用 | 学生が自分のクール・班を確認する。閲覧のみで共有する |
| フォーム | クール申請フォーム | 学生がクールまたは BC を申請する |
| フォーム | パスワードフォーム | 学生がパスワードを発行・再発行する |

## セットアップ

### 1. フォームを作る

2つのフォームの質問文は、`CONFIG.HEADERS` の文字列と完全に一致させてください。一致していないと回答を読み取れません。

クール申請フォーム:

| 質問文 | 形式 | 必須 |
| --- | --- | --- |
| 学籍番号 | 記述式 | はい |
| パスワード | 記述式 | はい |
| 希望内容 | ラジオボタン | はい |
| 氏名 | 記述式 | 任意 |
| ベーシッククラスに参加しようと思った理由を記述してください。 | 段落 | 任意 |
| わからなかったところ | 段落 | 任意 |

「希望内容」の選択肢は `CONFIG.PREF_VALUE` と一致させます（`第1クール希望` 〜 `第4クール希望`、`BC（ベーシック）希望`）。`TOTAL_COOLS: 3` なら第4クールは不要です。

パスワードフォーム:

| 質問文 | 形式 | 必須 |
| --- | --- | --- |
| 学籍番号 | 記述式 | はい |
| 氏名 | 記述式 | 任意 |

### 2. フォームの回答先を管理用スプレッドシートにする

両方のフォームで「回答」タブ →「スプレッドシートにリンク」→ 管理用スプレッドシートを選びます。作られた回答シートの名前を次のように変更してください。スクリプトはシート名で、どちらのフォームから送られた回答かを判定します。

- クール申請フォームの回答シート → `クール申請フォーム`
- パスワードフォームの回答シート → `パスワードフォーム`

### 3. スクリプトを入れる

管理用スプレッドシートで「拡張機能」→「Apps Script」を開き、`コード.js` の中身を貼り付けます。

[clasp](https://github.com/google/clasp) を使う場合は、`clasp clone <スクリプトID>` で作られる `.clasp.json` を使って `clasp push` します。スクリプト ID は Apps Script の「プロジェクトの設定」にあります。`.clasp.json` は `.gitignore` に入っているので、コミットされません。

### 4. CONFIG に ID を入れる

`コード.js` の先頭にある `CONFIG` の、次の値を書き換えます。

| 項目 | 入れる値 | 確認する場所 |
| --- | --- | --- |
| `COURSE_NAME` | 授業名 | メールの件名と本文に入る |
| `STUDENT_SPREADSHEET_ID` | 学生共有用スプレッドシートの ID | URL `https://docs.google.com/spreadsheets/d/〇〇〇/edit` の 〇〇〇 |
| `STUDENT_ROSTER_SHEET_GID` | 学生共有用の「クール分け」にするシートの gid | そのシートを開いたときの URL 末尾 `#gid=〇〇〇`。最初のシートなら通常 `0` |
| `COOL_FORM_ID` | クール申請フォームの ID | フォーム編集画面の URL `https://docs.google.com/forms/d/〇〇〇/edit` の 〇〇〇 |
| `PASSWORD_FORM_ID` | パスワードフォームの ID | 同上 |
| `MAIL_DOMAIN` | 学生メールアドレスの `@` 以降 | 送信先は「学籍番号 + この値」になる。例: `@example.ac.jp` |

フォーム ID は編集画面の URL から取ります。学生に配る回答用 URL（`/forms/d/e/...`）に含まれる ID は別物なので、こちらを入れると動きません。

管理用スプレッドシートの ID は、スクリプトを紐づけたスプレッドシートから自動で取得するので、設定は不要です。

授業に合わせて、クール数（`TOTAL_COOLS`）、班数と人数（`TEAMS_PER_COHORT`、`MEMBERS_PER_TEAM`）、週次スケジュール（`WEEKLY_SCHEDULE`）、初回パスワードの送信日時（`INITIAL_PASSWORD_SETTINGS.SEND_SCHEDULE`）も変更してください。

### 5. 初期化してトリガーを登録する

管理用スプレッドシートを開き直すと、メニューバーに「自動化メニュー」が出ます。次の順に実行します。初回の実行時に権限の承認を求められます。

1. ①初期設定 →「必要シートを作成/更新」
2. ③フォーム送信 →「送信トリガーを有効化」
3. ⑦週次スケジュール →「週次スケジュール登録」

初回パスワードを事前に配る場合は、②初回パスワード送信 →「名簿シートを準備」を実行し、作られたシートの A列に学籍番号、B列に氏名を貼り付けてから「分割送信を開始」を実行します。

## 毎週の流れ（初期設定のスケジュール）

| 曜日・時刻 | 処理 |
| --- | --- |
| 金 11:50 | 前週のデータを初期化 |
| 金 12:15 | クール申請フォームの受付開始 |
| 木 21:00 | クール申請フォームの締切 |
| 木 21:01 | 班分け案を「グループ分け確認修正用」シートに出力 |
| 木 22:00 | 班分けを学生共有用シートに公開 |

班分け案の出力から公開までの間に、管理者が「グループ分け確認修正用」シートで班を手直しできます。

## 注意

- パスワードを含む「学籍・パスワード一覧」「パスワードログ」シートは管理用スプレッドシートにあります。管理用スプレッドシートは学生と共有しないでください。
- MailApp の送信上限は、一般の Google アカウントで1日100通です。受講者が多い場合は、初回パスワードの分割送信を使ってください。
