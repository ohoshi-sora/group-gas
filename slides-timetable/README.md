# グループワーク当日の時間割スライド（Google Apps Script）

グループワーク当日に投影する Google スライドの時間割表に、全体説明と各クールの開始・終了時刻を書き込む Google Apps Script（GAS）です。全体説明やクールの時間を変えたときに、時刻を手で計算し直さずに済みます。

## 書き込まれる時刻

初期値（開始 9:00、全体説明 40分、各クール 30分、クール間の休憩 5分、3クール）では、次のようになります。全体説明と第1クールの間には休憩を入れません。

| 行 | 開始 | 終了 |
|---|---|---|
| 全体説明 | 09:00 | 09:40 |
| 第1クール | 09:40 | 10:10 |
| 第2クール | 10:15 | 10:45 |
| 第3クール | 10:50 | 11:20 |

## 表の形

書き込み先は、2枚目のスライドにある1つ目の表です。表は次の形にしておきます。

- 1行目が全体説明、2行目から下が第1クール、第2クール…の順。クールの行数は `COOL_COUNT` と同じにする。
- 2列目に開始時刻、4列目に終了時刻が書き込まれる。1列目（項目名）と3列目（「〜」など）は変更されない。

## 使い方

1. 時間割のスライドを開き、「拡張機能 → Apps Script」を開きます。
2. 最初からあるコードを消し、このフォルダの `timetable.js` の内容をすべて貼り付けて保存します。
3. スライドを開き直すと、「スライド操作」メニューが出ます。初めて使うときは、Google アカウントの承認を求められます。

| メニュー | 動き |
|---|---|
| 全体説明時間を更新 | 全体説明の時間（分）を入力すると、表全体の時刻を書き直す |
| 各クール時間を更新 | 各クールの時間（分）を入力すると、表全体の時刻を書き直す |
| 初期値に戻す | 入力した時間を消し、`CONFIG` の初期値で書き直す |

入力した時間は、そのスライドファイルに保存されます。次に開いたときも、同じ値が使われます。

## 設定（`CONFIG`）

メニューで変えられるのは、全体説明と各クールの時間だけです。開始時刻・休憩・クール数を変えるときは、コード冒頭の `CONFIG` を書き換えて保存し、メニューのどれかを実行します。

| 項目 | 内容 | 初期値 |
|---|---|---|
| `SLIDE_INDEX` | 書き込むスライドの番号。0 から数えるので、1 は2枚目 | 1 |
| `TABLE_INDEX` | そのスライドの何番目の表か。0 から数える | 0 |
| `START_TIME` | 全体説明の開始時刻 | `"9:00"` |
| `DEFAULT_OVERVIEW_MIN` | 全体説明の時間（分）の初期値 | 40 |
| `SESSION_MIN` | 各クールの時間（分）の初期値 | 30 |
| `BREAK_MIN` | クールとクールの間の休憩（分） | 5 |
| `COOL_COUNT` | クール数。[グループ分け](../group-assign/README.md)の `TOTAL_COOLS` と合わせる | 3 |
