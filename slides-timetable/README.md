# グループワーク当日の時間割スライド（Google Apps Script）

グループワーク当日に投影する Google スライドの時間割表に、全体説明と各クールの開始・終了時刻と、各クールのグループ番号を書き込む Google Apps Script（GAS）です。全体説明やクールの時間を変えたときに、時刻やグループ番号を手で計算し直さずに済みます。

## 書き込まれる時刻

初期値（開始 9:00、全体説明 40分、各クール 30分、クール間の休憩 5分、3クール）では、次のようになります。全体説明と第1クールの間には休憩を入れません。

| 行 | 開始 | 終了 |
|---|---|---|
| 全体説明 | 09:00 | 09:40 |
| 第1クール | 09:40 | 10:10 |
| 第2クール | 10:15 | 10:45 |
| 第3クール | 10:50 | 11:20 |

## グループ番号

クール行の1列目は、「第Nクール」と「グループ番号：a~b」の2行で書き直されます。グループ番号は、group-assign と同じく、クールごとに `TEAMS_PER_COHORT` 個ずつの通し番号です。`TEAMS_PER_COHORT` が 8 なら、第1クールが 1~8、第2クールが 9~16、第3クールが 17~24、第4クールが 25~32 になります。

## 表の形

書き込み先は、2枚目のスライドにある1つ目の表です。表は次の形にしておきます。

- 1行目が全体説明、2行目から下が第1クール、第2クール…の順。
- 表の行数が「全体説明の1行 ＋ `COOL_COUNT` 行」と合わないときは、書き込む前に、最後の行の下に行を足すか、末尾の行を消す。足した行の3列目には「~」を入れる。表の位置と大きさは自動では変わらないので、行を足して表がスライドの下の文と重なったら、表の大きさを手で直す。
- 2列目に開始時刻、4列目に終了時刻が書き込まれる。
- クール行の1列目は、上の「グループ番号」の形で書き直される。手で書いた文言は消えるので、文言を変えたいときはコードの `buildCoolLabel` を直す。
- 全体説明の行の1列目と、3列目（「~」など）は変更されない。

## 使い方

1. 時間割のスライドを開き、「拡張機能 → Apps Script」を開きます。
2. 最初からあるコードを消し、このフォルダの `timetable.js` の内容をすべて貼り付けて保存します。
3. スライドを開き直すと、「スライド操作」メニューが出ます。初めて使うときは、Google アカウントの承認を求められます。

| メニュー | 動き |
|---|---|
| 全体説明時間を更新 | 全体説明の時間（分）を入力すると、表全体の時刻を書き直す |
| 各クール時間を更新 | 各クールの時間（分）を入力すると、表全体の時刻を書き直す |
| 初期値に戻す | 入力した時間を消し、`CONFIG` の初期値で書き直す |
| 表を書き直す（CONFIG の変更を反映） | 入力済みの時間はそのままで、`CONFIG` の今の値で表全体を書き直す |

入力した時間は、そのスライドファイルに保存されます。次に開いたときも、同じ値が使われます。

## 設定（`CONFIG`）

メニューで変えられるのは、全体説明と各クールの時間だけです。開始時刻・休憩・クール数・グループ数を変えるときは、コード冒頭の `CONFIG` を書き換えて保存し、「表を書き直す」を実行します。

| 項目 | 内容 | 初期値 |
|---|---|---|
| `SLIDE_INDEX` | 書き込むスライドの番号。0 から数えるので、1 は2枚目 | 1 |
| `TABLE_INDEX` | そのスライドの何番目の表か。0 から数える | 0 |
| `START_TIME` | 全体説明の開始時刻 | `"9:00"` |
| `DEFAULT_OVERVIEW_MIN` | 全体説明の時間（分）の初期値 | 40 |
| `SESSION_MIN` | 各クールの時間（分）の初期値 | 30 |
| `BREAK_MIN` | クールとクールの間の休憩（分） | 5 |
| `COOL_COUNT` | クール数。表の行数もこれに合わせて増減する。[グループ分け](../group-assign/README.md)の `TOTAL_COOLS` と合わせる | 3 |
| `TEAMS_PER_COHORT` | 1クールのグループ数。グループ番号の計算に使う。グループ分けの `TEAMS_PER_COHORT` と合わせる | 8 |
